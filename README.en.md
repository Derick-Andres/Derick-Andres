**Full-Stack Developer | Backend and Infrastructure**

I build web applications and enjoy figuring out what happens after the code leaves my editor. I like working through how an application gets deployed, how its services communicate, and how to troubleshoot it when something breaks.

I've worked on **ERP systems, point-of-sale software, and tax document integrations**, as well as deploying and maintaining applications in Linux environments. I'm studying Computer Science at **UDESC** in Joinville, Brazil, and deepening my knowledge of **computer networking and DevOps**.

## Selected Experience

- **Financial ERP** — Implemented business rules for a chart of accounts and cost centers, including transactional setup of default records. Covered the workflow with automated tests.
- **Point of Sale and Tax Document Issuance** — Worked on sales and cancellation rules and integrated the POS with an electronic tax document provider.
- **Infrastructure and Deployment** — Helped migrate a POS deployment from Coolify to SaveInCloud by updating the Nginx configuration and deployment scripts.
- **Distributed Processing** — Built a wallet transaction processor for a technical challenge using NestJS, PostgreSQL, and SQS. The service handled concurrent operations, idempotent requests, and duplicate messages.
